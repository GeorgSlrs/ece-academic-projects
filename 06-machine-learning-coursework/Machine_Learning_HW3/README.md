# Machine Learning — HW3

## What this assignment covers
MATLAB experiments on conditional expectation, data-driven approximation and sequential decision/reinforcement-learning problems. The files compare numerical integration/value-function calculations with shallow neural-network approximations and policies.

## Main files
- `Machine_Learning_hw3_1_a.m` — conditional-expectation approximation and neural-network comparison.
- `Machine_Learning_hw3_2_a.m`, `Machine_Learning_hw3_2_b.m` — value functions, policies and generated state-transition data.
- `Machine_Learning_hw3_3.m` — discounted infinite-horizon value/policy experiment.
- `ShortSightedReinforcementLearning_Revised.m` — short-sighted RL comparison.
- `GEORGIOS-SALIARHS-3.docx` — submitted work/report.
- `Moustakides 2024.pdf` — reference material included with the coursework.

## Requirements
- MATLAB
- Statistics and Machine Learning Toolbox is required for functions such as `normcdf` used by several scripts.

## Run
Open the folder in MATLAB and run the desired `.m` file, for example:

```matlab
Machine_Learning_hw3_3
```

Some files define functions whose filename/function name may reflect historical revisions; if MATLAB warns about a mismatch, run the function shown at the top of that file or rename a local copy.

These are separate homework experiments rather than one production ML application. This is academic coursework; see the repository-level authorship note for context.
