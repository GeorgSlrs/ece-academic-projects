# Machine Learning Coursework

Coursework series spanning statistical classification, image reconstruction, conditional expectation and sequential decision/reinforcement-learning experiments.

## Subprojects
- [HW1](Machine_Learning_HW1/) — Bayes classification and neural-network experiments.
- [HW2](Machine_Learning_HW2/) — MATLAB latent/image reconstruction.
- [HW3](Machine_Learning_HW3/) — conditional expectation, value functions and RL-style experiments.

Each homework directory contains a setup/run guide and points to the relevant report/source files.
