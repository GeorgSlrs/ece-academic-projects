# ECE Academic Projects

Selected academic coursework and project artifacts from my Electrical & Computer Engineering studies at the University of Patras.

## Scope and authorship

This repository is an **academic coursework portfolio**, not a claim that every line was produced independently. Some projects were completed in teams and some code was developed with coding-assistant support. The descriptions below intentionally focus on the topics, methods, and work I can discuss rather than claiming sole authorship of complete systems.

## Projects

1. [Introduction to Robotics](01-introduction-to-robotics/) — transformations, kinematics, trajectories, feedback control, URDF-based dynamics
2. [Particle Filter-Based SLAM](02-particle-filter-slam/) — differential-drive modelling, particle filtering, simulated sensing and mapping
3. [Quality-Diversity Quadruped Locomotion](03-quality-diversity-quadruped/) — MAP-Elites / SAIL coursework with a Minitaur model
4. [Linear & Combinatorial Optimization](04-linear-combinatorial-optimization/) — LP/Simplex and a larger MILP scheduling formulation
5. [Algorithms & Data Structures](05-algorithms-data-structures/) — maximum subarray and running median exercises
6. [Machine Learning Coursework](06-machine-learning-coursework/) — classification, neural-network and estimation exercises
7. [Frogger Arcade Game](07-frogger-arcade-game/) — early Python team project
8. [Digital Twins Research](08-digital-twins-research/) — individual research paper summary
9. [High-Impulse Voltage Measurement](09-high-impulse-voltage-measurement/) — laboratory measurement/data-analysis summary

Large course datasets, duplicate drafts, cache files, and reports containing student identifiers have intentionally been excluded from this public-ready version.
