# ECE Academic Projects

Academic coursework and project artifacts from my Electrical & Computer Engineering studies at the University of Patras.

## Scope and authorship

This is an **academic coursework portfolio**, not a claim that every line was produced independently. Some projects were completed in teams and some code was developed with coding-assistant support. Project folders preserve the original coursework/source material where available and descriptions avoid claiming sole authorship of complete systems.

## Repository file policy

The goal is to preserve the **actual project material**, not merely summaries. Source code, notebooks, configuration files, small data/result files and supporting artifacts are kept in their corresponding project folders. The original portfolio also contains larger binary reports/presentations and some third-party/generated material. Caches, virtual environments, executable build artifacts, duplicated drafts, large third-party datasets and teammates' private personal reports are intentionally excluded from the public repository.
