# ECE Academic Projects

Full project-file mirror prepared from my Electrical & Computer Engineering coursework and project archives.

This repository contains source code, notebooks, reports, presentations, figures, small result/data files, and supporting assets grouped by project. Some projects were team coursework and some code used coding-assistant support; inclusion here is not a claim of sole authorship.

Recent recovered additions include the hardware-oriented adaptive-control DC-motor laboratory, the inverted-pendulum half of the robust-control coursework, and the Quantum Game of Life science-communication artifact.

Large third-party datasets, virtual environments, caches/build artifacts, and teammates’ private personal reports are excluded.
