# Java Spaceship Coursework

A Swing spaceship exercise with selectable ship classes, navigation, laser objects, and a game window sized to the desktop display.

## Contents

- `src/main/MainClass.java`: application entry point.
- `src/gui/`: selection and gameplay screens.
- `src/spaceships/` and `src/spaceships_laserguns/`: ship, navigation, and laser classes.
- `Resources/images/`: supplied ship images.
- `original-coursework-notes.txt`: original explanation of the work and its limitations.

## Running the coursework

Use a JDK and a Java IDE. Compile the package tree and launch `main.MainClass`. Add `Resources` to the runtime classpath if required by the resource-loading code. The original audio files are omitted; audio features may require replacement assets in `Resources/audio`.
