# Robotic Systems II — Homework 1

Simulation and constrained control exercises for a one-mass hopper, with numerical integration comparisons and a NumPy quadratic-programming solver.

## Contents

- `RS_II_HW_1_1.py`: interactive hopper simulation and integration methods.
- `RS_II_HW_1_2.py`: equality-constrained QP reduction and primal–dual solution.
- `RS_II_HW_1_3.py`: combines simulation with QP-based control.

## Running the coursework

Use Python 3 with NumPy and Matplotlib. Run each script from this folder, for example `python RS_II_HW_1_1.py`. The graphical programs need a desktop plotting backend.
