# Robotic Systems II Coursework

Coursework artifacts spanning nonlinear control, optimization, TVLQR and a hardware-oriented continuation.

## Subprojects
- [HW2](hw2/) — planar quadrotor control with PD/LQR/MPC-style studies and saved results.
- [HW3](hw3/) — double-pendulum trajectory optimization and TVLQR tracking.
- [HW4](hw4/) — revised physical model, cached TVLQR trajectory and pyCandle/CAN hardware runner.

Each homework folder contains its own setup/run guide.

Some code was developed with coding-assistant support; the repository preserves the coursework artifacts without claiming sole authorship of every line.
