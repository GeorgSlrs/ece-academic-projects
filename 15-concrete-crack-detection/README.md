# Concrete Crack Detection

Team machine-learning project on image-based concrete/surface crack classification. The source here is a cleaned copy of the team repository, excluding the large dataset, trained model binaries, cache files, Git metadata, and other bulky artifacts.

The original team repository was maintained by another team member. This copy is included as part of my academic portfolio and **does not claim sole authorship**.

Technologies in the project include Python, TensorFlow/Keras, image preprocessing, dataset validation, training/evaluation scripts, and visualization.
