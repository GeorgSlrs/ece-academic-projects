# C Programming Practice Collection

## What this folder contains
A chronological/practice collection of small C programs rather than one single application. Topics include arrays, strings, pointers, dynamic memory, structs, command-line arguments, sorting/searching, recursion, I/O and standard memory/string functions.

## Requirements
- A C compiler such as GCC/MinGW-w64, Clang, or MSVC.
- Most files use only the C standard library.
- A few exercises may contain compiler/platform-specific functions from the environment in which they were originally written.

## Compile an individual exercise
With GCC, for example:

```powershell
gcc .\binary_search.c -o binary_search.exe
.\binary_search.exe
```

Or:

```powershell
gcc .\pointers1.c -o pointers1.exe
.\pointers1.exe
```

## Notes
These files represent learning/practice progression, so quality and style vary and some may be intentionally small or experimental. They should not be interpreted as production software. See the repository-level authorship note for context.
