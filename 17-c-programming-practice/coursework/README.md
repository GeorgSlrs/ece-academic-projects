# Procedural Programming — C Coursework

Selected substantial C exercises from the procedural-programming course, retaining one advanced local version of each program.

## Contents

- `shape-printing/`: menu-driven ASCII shapes.
- `matrix-temperature/`: matrix evolution, extrema, histograms, and convergence.
- `text-dictionary/`: text-file processing and dictionary operations.
- `character-frequency/`: linked character-frequency records.
- `linked-lists/`: operations on linked integer lists.

## Running the coursework

Compile each `main.c` separately with a C compiler, for example `gcc main.c -o exercise`. These programs are independent executables, not one combined build. Some original comments use a legacy Greek encoding. The dictionary program expects user-selected input files.

## Archive notes

Preserved as coursework; full execution and numerical results have not been revalidated.

Scratch programs, build output, and superseded iterations are omitted. Original source comments and attributions are preserved.
