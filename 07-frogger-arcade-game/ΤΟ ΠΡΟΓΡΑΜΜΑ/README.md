# Frogger — Runnable Game Files

## What this folder contains
The runnable Python/Tkinter/Turtle game and its image assets. The surrounding parent folder contains the team report, presentation and installation documents.

## Main files
- `menu.py` — Tkinter start/menu window.
- `frogger.py` — main Frogger game implementation.
- `*.gif`, `menupic.png` — sprites and UI/background assets.

## Requirements
- Python 3 with Tk/Tkinter support
- Python standard-library modules used here include `turtle`, `tkinter`, `math`, `time`, `random`, and `os`.
- No pip-installed third-party package is required by these two scripts.

## Run
Keep all image assets in this same folder.

```powershell
py .\menu.py
```

If the menu's launcher does not start the game on your system, run the game directly:

```powershell
py .\frogger.py
```
