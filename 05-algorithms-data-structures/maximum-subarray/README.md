# Maximum Subarray — Algorithm Comparison

## What this assignment covers
Comparison of several approaches to the Maximum Subarray problem, from slower brute-force methods through divide-and-conquer to Kadane's linear-time algorithm.

## Main files
- `main.py` — benchmark/driver script.
- `max_subarray.py` — implementations of the algorithms.
- `random_arr.py` — random input generation.
- `Max_Subarray_Report.docx` — coursework report.

## Requirements
- Python 3
- No third-party packages are required.

## Run
```powershell
py .\main.py
```

## Important runtime note
The benchmark uses very large arrays for the faster algorithms. On a modest machine this can consume substantial memory and time. Reduce the sizes in `main.py` before experimenting if necessary.
