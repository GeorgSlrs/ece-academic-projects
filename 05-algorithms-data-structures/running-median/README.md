# Running Median / Heap-Based Data Processing

## What this assignment covers
A custom heap-based implementation used to process a stream of synthetic measurements and maintain/query median-style information efficiently. The source includes custom point/measurement classes and heap operations.

## Main files
- `ex3.py` — complete implementation and driver code.
- `algo_3.docx` — coursework report/documentation.

## Requirements
- Python 3
- Standard library only (`random`, `time`, `sys`).

## Run
```powershell
py .\ex3.py
```

## Notes
The script can generate large synthetic workloads, so execution time depends on the configured number of points/measurements. This is academic coursework; see the repository-level authorship note for context.
