# Classical Control Systems

MATLAB exercises in transfer functions and state-space models, transient response, PID tuning, root-locus design, frequency response, and elementary motor/cruise-control models.

## Contents

- `exercises/ask/`: model conversion and time responses.
- `exercises/ask2/`: responses and PID examples.
- `exercises/ask3/`: root-locus and feedback examples.
- `exercises/ask4/`: Bode plots, margins, and tracking.
- `reference-examples/`: small model-conversion and response examples.

## Running the coursework

Run an individual `.m` script in MATLAB. Most scripts require Control System Toolbox; the symbolic differential-equation example also requires Symbolic Math Toolbox.
