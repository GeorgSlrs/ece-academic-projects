# Linear and Combinatorial Optimization — Coursework

Homework programs for linear-programming geometry, primal/dual solutions, integer optimization, and branch-and-bound knapsack search.

## Contents

- `hw1/`: graphical feasible-region and optimization exercises.
- `hw2/`: linear-programming duality, integer optimization, and branch-and-bound examples.

## Running the coursework

Use Python 3 with NumPy, Matplotlib, SciPy, SymPy, and PuLP as required by each script. Run scripts from their homework directory; `hw2/requirements.txt` records the supplied environment.

## Archive notes

Preserved as coursework; full execution and numerical results have not been revalidated.

The programs preserve original comments and references. Reports containing student identifiers are omitted.
