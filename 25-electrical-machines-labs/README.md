# Electrical Machines Laboratories

Group laboratory work on DC-machine measurements and Simulink models, plus MATLAB plots of synchronous-machine characteristics.

## Contents

- `dc-machine-measurements/`: measurement plots and efficiency calculations.
- `dc-machine-simulation/`: separately excited, series, and compound DC-machine models and torque/speed plots.
- `synchronous-machine/`: excitation-current, stator-current, and open-circuit characteristic plots.

## Running the coursework

Use MATLAB for plotting scripts and MATLAB/Simulink for `.slx` models. Open a model in its own directory; additional electrical-machine block libraries depend on the original course installation.
