# Numerical Analysis

MATLAB exercises for nonlinear systems, linear iterative methods, interpolation, and curve fitting.

## Contents

- `nonlinear-systems/`: Newton iteration with `mainScript.m`, `newtonsMethod.m`, and `systemEquations.m`.
- `curve-fitting/`: correlation-based model fitting, coefficients, and Lagrange interpolation.
- `jacobi-iteration/`: Jacobi linear-system solver and driver.

## Running the coursework

Use MATLAB. Change to an exercise directory and run `mainScript.m`, keeping its helper functions on the MATLAB path.

## Archive notes
