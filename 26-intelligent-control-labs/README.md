# Intelligent Control Laboratories

Course notebooks exploring dynamic programming, temporal-difference learning, neural-network optimization, and continuous-control reinforcement learning.

## Contents

- `IC_Lab_1.ipynb`: grid-world policy evaluation.
- `IC_Lab_2_v1.ipynb`: cliff-world temporal-difference learning.
- `IC_Lab_3.ipynb`: Adam optimization and neural-network function approximation.
- `IC_Lab_4.ipynb`: Q-learning with function approximation for a pendulum.
- `IC_Lab_5.ipynb`: deterministic policy-gradient control.
- `IC_Lab_6.ipynb`: TD3-style cart-pole control and replay buffers.

## Running the coursework

Open the notebooks with Jupyter using Python 3. Dependencies include NumPy, Matplotlib, and PyTorch. Execute cells in order; training cells may take substantial time.
