# Inverted-Pendulum SISO Robust-Control Coursework

## Overview
This subproject contains the inverted-pendulum half of the robust-control team coursework. The system is a cart–pendulum model where horizontal cart force is the actuator and pendulum angle is the primary regulated output.

## Files
- `Robust_Control_Team_Project_SISO_with_control.html` — recovered browser-based interactive simulation/playground using the Canvas 2D API and no external JavaScript libraries.
- `SiSo_inv_pend_theta_stabilization_public.md` — text export of the associated Word write-up covering modelling, theta stabilization, controller tuning, force/angle constraints and the prefilter discussion.

## Run the interactive simulation
Open `Robust_Control_Team_Project_SISO_with_control.html` in a modern browser. No package installation is required for the HTML artifact.

## Notes
The original Word document contains equations and embedded figures that cannot be represented perfectly in a plain-text GitHub export; the public Markdown keeps the recoverable written content. This is team coursework and some implementation work used coding-assistant support, so the folder should not be read as a claim of sole authorship of the complete implementation.
