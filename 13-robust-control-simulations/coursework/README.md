# Robust Control — Homework and Laboratory

MATLAB and Python exercises in feedback-controller design, multivariable analysis, uncertainty modeling, and experimentally measured DC-motor dynamics.

## Contents

- `hw1/`: P, PI, PID, inverse-based, and mixed-sensitivity designs.
- `hw2/`, `hw3/`, `hw4/`: later course exercises.
- `laboratory/`: Bode measurements, uncertainty modeling, and robust-controller analysis with measurement tables.

## Running the coursework

Python exercises use NumPy, Matplotlib, python-control and, for some operations, Slycot. MATLAB exercises require Control System Toolbox; robust synthesis uses Robust Control Toolbox, and the supplied HW1 notes also list Optimization Toolbox. Run files individually from their folder.
