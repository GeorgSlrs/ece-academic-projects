# Java Swing Calculator

A Java course project combining a Swing calculator interface with infix-to-postfix conversion, postfix checks, and stack-based expression evaluation.

## Contents

- `src/mainPacket/MainClass.java`: application entry point.
- `src/GUI_1/`: calculator window and buttons.
- `src/conversions/`: expression conversion, validation, and evaluation.

## Running the coursework

Use a Java Development Kit and an IDE or `javac`. Compile all Java files preserving package directories, then launch `mainPacket.MainClass`. A desktop Java environment is required for Swing.
