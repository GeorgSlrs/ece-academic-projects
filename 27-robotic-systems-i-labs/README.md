# Robotic Systems I Laboratories

Course laboratory notebooks for rigid-body transformations, mobile-robot motion planning, rotation/pose trajectory generation, and Kalman filtering.

## Contents

- `RS1_Lab_1.ipynb`: rotations, homogeneous transforms, and spatial velocities.
- `RS1_Lab_2.ipynb`: car-like kinematics and RRT motion planning.
- `RS1_Lab_4.ipynb`: cubic trajectory generation on SO(3) and SE(3).
- `RS1_Lab_5.ipynb`: Kalman filtering for a double-integrator model.

## Running the coursework

Open with Jupyter and Python 3, with NumPy, Matplotlib, and SciPy installed. Execute cells in order. Some explanatory images such as `car.png` were not present in the source folder, so those illustrations may be missing.
