# Adaptive Control — HW2

## What this assignment covers
MATLAB adaptive-control experiments. The included scripts explore model-reference adaptive control (MRAC) and normalized MIT-rule style parameter adaptation, with performance plots and comparisons.

## Main files
- `ACRL_HW2_Ex1.m` — normalized MIT-rule MRAC experiment and parameter/error analysis.
- `ACRL_HW2_Ex2.m` — second homework exercise.
- `report (1).pdf` / `report.docx` — coursework report.

## Requirements
- MATLAB

## Run
Open this directory as the MATLAB Current Folder and run each script from the Command Window or editor:

```matlab
ACRL_HW2_Ex1
ACRL_HW2_Ex2
```

## Expected output
Time histories, parameter/adaptation plots and error/performance figures.
