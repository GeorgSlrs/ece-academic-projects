# Adaptive Control — HW3

## What this assignment covers
Adaptive augmentation for a stepper-motor model with an RBF neural-network disturbance/uncertainty term. The script compares sigma/e modification and projection variants and evaluates tracking/error metrics.

## Main files
- `ACRL_HW_3.m` — complete MATLAB simulation.
- `ACRL_HW_3_Report_v1.pdf` / `.docx` — report.

## Requirements
- MATLAB
- Control System Toolbox is required for `lyap`.

## Run
```matlab
ACRL_HW_3
```

Run the script from this folder in MATLAB. It generates multiple comparison, tracking and error figures.

## Notes
Controller parameters and projection bounds are coursework/simulation values, not validated hardware settings. This is academic coursework; see the repository-level authorship note for context.
