# Adaptive Control — Homework 1

Nonlinear-system stability and Lyapunov analysis, explored through MATLAB phase portraits, equilibrium searches, attraction-region estimates, and exponential-decay comparisons.

## Contents

- `ACRL_Ex_1_1.m` through `ACRL_Ex_1_4.m`: four exercises.
- `ACRL_Ex_1_3_sols.m`: equilibrium search for the nonlinear system in Exercise 3.

## Running the coursework

Open an exercise in MATLAB and run it. The scripts use numerical ODE integration and plotting; Exercise 3 includes a fallback when `lyap` is unavailable.
