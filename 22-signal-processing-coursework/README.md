# Signals, Systems, and Digital Signal Processing

Python and MATLAB coursework covering signal visualization, sampled stochastic processes, autocorrelation and power spectra, FFT convolution, filter responses, and ECG-signal filtering.

## Contents

- `signals-and-systems/`: three homework sets of signal/system plots.
- `digital-signal-processing/hw1/`: sample realizations, autocorrelation, and power spectral density.
- `digital-signal-processing/hw2/`: FFT and convolution examples.
- `digital-signal-processing/hw3/`: Butterworth/frequency-response plots and ECG filtering.
- `digital-signal-processing/matlab-lab/`: MATLAB signal analysis and input data.

## Running the coursework

Use Python 3 with NumPy, Matplotlib, and SciPy. Run each script from its own homework directory so relative CSV/text inputs resolve. The MATLAB lab needs MATLAB and its supplied `.mat` data.
