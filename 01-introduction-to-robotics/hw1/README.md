# Introduction to Robotics — HW1

## What this assignment covers
Rigid-body coordinate transforms and 3D visualization. The Python script defines homogeneous transformations for simple objects, manipulates their poses, and visualizes reference frames and geometry.

## Main files
- `Robotics_HW1_code.py` — main executable script.
- `Robotics_HW1_Report.pdf` / `.docx` — assignment report.
- `Figure_1.png` — saved result/illustration.

## Requirements
- Python 3
- NumPy
- Matplotlib

## Install
On Windows, from this folder:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install numpy matplotlib
```

## Run
```powershell
py .\Robotics_HW1_code.py
```

The script opens Matplotlib 3D figures.
